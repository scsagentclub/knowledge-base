# Knowledge Base

个人 GitHub 项目知识库，收录整理值得关注的开源项目，按领域分类归档。

## 分类目录

- **hardware-dev** — 硬件开发（嵌入式、IoT、机器人、ESP32 等）
- **solo-business** — 一人公司（SaaS、独立开发、副业变现、营销工具）
- **agent-dev** — Agent 开发（AI Agent、LLM、MCP、RAG、自动化）
- **useful-tools** — 好用工具（CLI、效率工具、开发者工具）
